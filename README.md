

# ITSFOUR_ HUB

Personal Developer Hub built with HTML, CSS, JavaScript and Markdown.

## Features

- Developer Terminal UI
- Responsive design
- Markdown publications
- Individual article pages
- Search publications
- Shareable article URLs
- GitHub Pages support

## Publishing

1. Upload all files to your GitHub repository.
2. Open Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save.

Your website will be published through GitHub Pages.

## Adding a publication

1. Create a `.md` file inside `posts/`.
2. Add its metadata.
3. Register the post inside `posts/index.json`.
4. Commit your changes.
